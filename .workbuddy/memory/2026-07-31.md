# 2026-07-31 工作日志

## nomedia-scan 项目启动

- **需求**：安卓手机 150G 含 `.nomedia` 的图片文件夹，临时移出 `.nomedia` 触发媒体扫描 → 网盘「相册备份」通道备份 → 备份完恢复 `.nomedia` 隐藏。
- **决策**：做 Android App，内置**两种模式**（Shizuku 推荐 + SAF 低权限兜底）；当前先出方案文档，待用户确认后开发。
- **产物**：`docs/技术方案.md`（含原理、权限矩阵、双模式实现、分批扫描策略、风险对策、M0 原理验证计划）。
- **关键结论**：
  - 扫描触发主方案 = `MediaScannerConnection.scanFile(目录)`，Android 11+ 递归扫描；`MEDIA_SCANNER_SCAN_FILE` 广播 Android 11+ 已移除。
  - 150G 索引耗时 20min~数小时，必须按子目录分批 + 进度显示 + 可续扫（ROM 有扫描上限）。
  - 恢复清理 = 放回 .nomedia 后重扫目录（系统自动清索引），Shizuku 模式附加 `content delete` 双保险。
  - SAF treeUri → 真实路径解析需兼容 `primary:` / `raw:` 两种格式。
- **环境**：本机 Java 22 + adb 有，Android SDK/Gradle 缺；SDK 计划装 `D:\Vibe-Coding\android-sdk`，GRADLE_USER_HOME 指 D 盘（C 盘紧张）。
- **技术栈决策**：Kotlin + 经典 View（不用 Compose），minSdk 26 / targetSdk 34，版本 0.1.0-beta。
- **待确认**：手机型号/Android 版本/ROM、.nomedia 分布（仅根目录 or 每个子目录）、网盘 App、是否已装 Shizuku、是否含视频。

## 转向 GitHub Actions 云构建 + Release（方案变更）

- **变更**：不装本地 Android SDK，改用 GitHub Actions 云构建发布（照抄 jp-media-viewer 模式）。
- **仓库**：https://github.com/NoNameLeGo/nomedia-scan（public，`android/` 子目录工程，AGP 8.2.2 + Kotlin 1.9.22 + Gradle 8.14.3 wrapper 复制自 jp-media-viewer）。
- **版本**：beta0.0.1（versionCode 1），已发布 Release：签名 APK `nomedia-scan-beta0.0.1-release.apk`（2MB）。
- **签名**：keytool 生成 `keystore/release.jks`（gitignored）+ 密码在 `keystore/keystore-password.txt`；4 个 Secrets 已配：`ANDROID_RELEASE_KEYSTORE_BASE64` / `STORE_PASSWORD` / `KEY_ALIAS=nomedia-scan` / `KEY_PASSWORD`。
- **技术栈（最终）**：Kotlin + 经典 View（appcompat/material/recyclerview/documentfile/lifecycle/coroutines），minSdk 26 / targetSdk 34。
- **核心代码结构**：`core/`（ScanManager 状态机、MediaScanner 分批扫描、MediaStoreQuery 计数、ScanService 前台服务、Notifications、ShizukuRunner）+ `fileops/`（FileOp 接口、ShizukuFileOp shell 实现、SafFileOp DocumentFile 实现）+ MainActivity。
- **关键踩坑（重要，防再犯）**：
  1. **shizuku api 版本**：13.1.5 的 `Shizuku.newProcess` 是 **private**（不公开）→ 降级 **12.2.0** 才是 public，返回 `rikka.shizuku.ShizukuRemoteProcess`（标准 Process API：getInputStream/waitFor）。
  2. **包名**：是 `rikka.shizuku.Shizuku`（不是 dev.rikka.shizuku）；监听器接口 `Shizuku.OnBinderReceivedListener`（方法 onBinderReceived）。
  3. Kotlin 字符串模板里写 shell 的 `${1%.bak}` 必须转义为 `\${1%.bak}`（否则被当 Kotlin 表达式报 "Expecting an element"）。
  4. lint 需 `abortOnError = false`（hidden API 引用不再让 release lintVital 失败）。
  5. `gh secret set` 无 `--body-file`，keystore 用 stdin 重定向。
- **流程验证**：push main 触发 debug 构建；tag（`beta*`/`v*`）触发 build + 签名 release + softprops/action-gh-release 发布，release notes 用 `.github/release-notes.md`。
- **待办**：用户真机安装验证（需连 adb 装 APK）、M0 原理验证（150G 索引耗时/ROM 限制实测）、续扫功能后续版本。
